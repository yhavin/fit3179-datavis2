# The State of the Parks

A presentation of the national parks of the contiguous United States, 2012-2021

Live visualisation: [click here](https://yhavin.github.io/fit3179-datavis2/)

This project was undertaken as part of FIT3179 during my Computer Science degree at Monash University. It contains interactive data visualisations built with Vega-Lite, educating users about:
- Which parks get the most visitors  
- Which seasons of the year are most popular  
- What camping style visitors prefer  
- When each park was established

*The full project report is not included in this repo due to university rules.*
